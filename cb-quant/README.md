# CB Quant 워크플로

전환사채(CB) 퀀트 트레이더의 하루 흐름을 그래프 워크플로로 실행하고, 진행 상황을 브라우저에서 실시간으로 보는 작업공간입니다. Google ADK(Agent Development Kit)의 그래프 워크플로 위에서 동작합니다.

**표본(가상) 데이터로만 동작하며 실제 주문을 보내는 기능은 없습니다.** `data/sample_universe.csv`의 종목·가격은 모두 만들어 낸 값입니다.

## 그래프

```
시장 데이터 수집 → CB 가격평가 → 신호 생성 → 리스크 점검
리스크 점검 ─[통과]────→ 사람 승인 → 결정 기록 → 리포트 작성
리스크 점검 ─[한도 초과]→ 포지션 축소 → 리스크 점검 (다시 점검)
리스크 점검 ─[대상 없음]→ 리포트 작성
```

| 단계 | 하는 일 |
|---|---|
| 시장 데이터 수집 | CSV에서 종목별 주가·변동성·금리·신용스프레드·시장가를 읽습니다. |
| CB 가격평가 | 이항 트리로 모델가, 패리티, 채권가치, 델타, 베가를 계산합니다. |
| 신호 생성 | 모델가가 시장가보다 기준(3%) 이상 높으면 매수 티켓을 만들고, 델타만큼 주식 매도 헤지를 붙입니다. |
| 리스크 점검 | 발행사별 한도, 총액 한도, 신용스프레드 한도를 확인해 경로를 정합니다. |
| 포지션 축소 | 신용스프레드 한도를 넘는 종목은 빼고, 나머지는 한도에 맞게 줄입니다. |
| 사람 승인 | 실행을 멈추고 화면에서 승인/반려를 기다립니다. |
| 리포트 작성 | 결과를 `reports/`에 Markdown 파일로 저장합니다. |

## 실행

Python 3.11 이상이 필요합니다.

```cmd
cd cb-quant
python -m pip install -r requirements.txt
python -m cbquant.server
```

브라우저에서 http://127.0.0.1:8765 를 열고 **실행**을 누릅니다. 노드가 실행 중·완료·사람 응답 대기·실패 상태에 따라 색이 바뀌고, 지나간 경로가 강조됩니다. 노드를 클릭하면 그 단계의 결과를 볼 수 있습니다. 각 단계는 실제로는 순식간에 끝나므로, 눈으로 따라갈 수 있게 "단계 표시 시간"만큼 화면에 머물게 했습니다.

다른 포트를 쓰려면 `python -m cbquant.server --port 9000`.

## 내 데이터와 기준으로 바꾸기

- 종목: `data/sample_universe.csv`와 같은 열 구성의 CSV를 만들고 `cbquant/graph.py`의 `DEFAULT_CONFIG["universe_path"]`를 바꿉니다. 가격은 액면 100 기준, 금리·스프레드·변동성은 소수(3% = 0.03), `conversion_ratio`는 액면 100당 받는 주식 수입니다. 콜·풋 조건이 없으면 비워 둡니다.
- 매수 기준, 종목당 금액, 리스크 한도: 같은 `DEFAULT_CONFIG`에 있습니다.
- 그래프 모양: `cbquant/graph.py`의 `build_workflow()`에서 노드와 연결선을 바꿉니다. 화면의 그래프는 여기서 자동으로 그려집니다.

## 가격평가 모델의 한계

신용위험은 "신용스프레드만큼의 확률로 부도가 나고 회수율은 0"이라는 단순한 가정으로 반영합니다. 콜은 발행사가 통지 기간 없이 즉시 행사한다고 보고, 풋은 지정일 하루만 행사할 수 있다고 봅니다. 전환가 조정(리픽싱), 배당 보호, 주식 대차 비용은 반영하지 않습니다. 실제 매매 판단에 쓰려면 이 부분을 먼저 보완해야 합니다.

## 구성

```
cbquant/pricing.py    CB 이항 트리 가격평가
cbquant/universe.py   CSV 읽기, 종목별 평가
cbquant/signals.py    저평가 판정, 티켓 크기와 헤지 계산
cbquant/risk.py       한도 점검과 포지션 축소
cbquant/report.py     리포트 작성
cbquant/graph.py      ADK 그래프 정의와 기본 설정
cbquant/runtime.py    그래프 실행, ADK 이벤트를 화면용 이벤트로 변환
cbquant/server.py     웹 서버 (실행, 실시간 이벤트 전송, 승인)
cbquant/static/       실시간 그래프 화면
```
